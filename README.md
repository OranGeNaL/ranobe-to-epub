# ranobelib-epub

Выгрузка книг с `ranobelib.me` в **EPUB 3** с фильтрацией символов под читалки
CrossPoint (диапазоны встроенного шрифта), сжатием иллюстраций и отчётом о потерях.

## Установка

Установка в одну строку — без Python, uv и прав администратора. Скрипт сам
определяет последнюю версию в [GitHub Releases](https://github.com/OranGeNaL/ranobe-to-epub/releases),
скачивает бинарный файл под вашу платформу и проверяет его контрольную сумму
SHA-256 по `checksums.txt` перед установкой.

macOS и Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/OranGeNaL/ranobe-to-epub/main/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/OranGeNaL/ranobe-to-epub/main/install.ps1 | iex
```

Бинарный файл устанавливается в `~/.local/bin` (macOS/Linux) или
`%LOCALAPPDATA%\Programs\ranobelib-epub` (Windows); путь можно переопределить
переменной окружения `RANOBELIB_EPUB_INSTALL_DIR`. Если директория не в `PATH`,
скрипт подскажет, как её добавить.

Сборок под macOS Intel нет: на таких машинах скрипт сообщит об этом и предложит
установку из исходников через uv (ниже). Перед запуском скрипт можно посмотреть:

```bash
curl -fsSL https://raw.githubusercontent.com/OranGeNaL/ranobe-to-epub/main/install.sh
```

## Использование

В терминале по умолчанию запускается TUI. Если ввод или вывод перенаправлены
(скрипт, CI), TUI не запускается и работает текстовый режим. Его же можно запросить
явно:

```bash
ranobelib-epub "<ссылка>" --no-tui
```

Примеры:

```bash
# ссылка на книгу или её slug_url
ranobelib-epub "https://ranobelib.me/ru/book/94231--rezero"

# только первые 20 глав, конкретный перевод, свой файл
ranobelib-epub "<ссылка>" --chapters 1-20 --team "Re:Zero | Элиор" --output book.epub

# без иллюстраций и без сжатия
ranobelib-epub "<ссылка>" --no-images --max-image-mb 0
```

### Параметры

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `slug_url` | — | Ссылка на книгу или её `slug_url` (`94231--rezero`). |
| `--output` | из названия книги | Путь к итоговому `.epub`. |
| `--chapters` | все | Выборка глав: диапазоны `1-50`, списки `1,3,5`, тома `v2`; можно смешивать: `1-3,7,10-12`. |
| `--team` | актуальная ветка | Имя команды-переводчика (сравнение без учёта регистра). |
| `--no-images` | выкл. | Не скачивать иллюстрации. |
| `--preset` | `medium` | Пресет сжатия: `max-quality`, `medium`, `max-compression`, `crosspoint` (см. ниже). Несовместим с `--max-image-mb`, `--max-image-width`, `--quality`. |
| `--max-image-mb` | `0.5` | Порог сжатия в МБ; `0` отключает перекодирование (исходные байты). PNG/GIF и изображения шире `--max-image-width` перекодируются в JPEG независимо от порога. |
| `--max-image-width` | `1280` | Максимальная ширина изображения после сжатия. |
| `--quality` | `80` | Качество JPEG, от 1 до 100. |
| `--charset` | `builtin` | Профиль набора символов (см. ниже). |
| `--rate-limit` | `4` | Запросов в секунду. |
| `--retries` | `3` | Число попыток на запрос. |
| `--no-tui` | — | Всегда текстовый режим, без интерфейса. |
| `--title` | с сайта | Название книги (`dc:title`). |
| `--author` | с сайта | Автор (`dc:creator`). |
| `--description` | с сайта | Описание (`dc:description`). |
| `--language` | с сайта | Код языка (`dc:language`) из набора: `ru`, `en`, `ja`, `zh`, `ko`, `de`, `fr`, `es`, `it`, `pt`. |
| `--subjects` | с сайта | Жанры через запятую (`dc:subject`). |
| `--date` | дата сборки | Дата в формате `YYYY-MM-DD` (`dc:date`). |
| `--publisher` | с сайта | Издатель (`dc:publisher`). |
| `--series` | с сайта | Название серии (EPUB 3 `belongs-to-collection`). |
| `--series-index` | с сайта | Номер тома в серии (`group-position`). |
| `--cover` | обложка книги | Идентификатор обложки тома (см. `--list-covers`). |
| `--no-cover` | — | Собрать EPUB без обложки. |
| `--list-covers` | — | Показать доступные обложки книги и завершиться без сборки. |

### Метаданные и обложка

Перед записью файла метаданные можно переопределить флагами (см. таблицу выше) или
на шаге «Метаданные и обложка» в TUI. Пустое значение поля означает «использовать
значение с сайта»: автор и описание приходят из карточки книги автоматически. Язык
выбирается из фиксированного набора из 10 языков. Идентификатор книги (`dc:identifier`)
всегда остаётся стабильным для одной книги и не переопределяется.

В TUI на этом шаге рядом со списком обложек показывается превью выбранной обложки: для
обложки по умолчанию — с сайта, для обложки тома — её изображение; на терминалах без
поддержки графики (Kitty TGP/Sixel) превью заменяется запасным вариантом.

Показ доступных обложек и сборка с обложкой тома:

```bash
# какие обложки есть у книги
ranobelib-epub "<ссылка>" --list-covers

# собрать с обложкой третьего тома (id из --list-covers)
ranobelib-epub "<ссылка>" --cover 18021735

# без обложки вообще
ranobelib-epub "<ссылка>" --no-cover

# переопределить название, автора, язык и серию
ranobelib-epub "<ссылка>" --title "Новое заглавие" --author "Имя автора" --language ru --series "Серия" --series-index 3
```

### Пресеты сжатия

Пресет задаёт сразу ширину, качество JPEG и порог в мегабайтах; `--preset` нельзя
сочетать с ручными `--max-image-width`, `--quality`, `--max-image-mb` — при конфликте
команда завершается ошибкой. Без параметров сжатия применяется `medium`.

| Пресет | Ширина | Качество | Порог | Назначение |
| --- | --- | --- | --- | --- |
| `max-quality` | 1600 | 92 | 5 МБ | Максимум детализации. |
| `medium` | 1280 | 80 | 0.5 МБ | По умолчанию: баланс качества и размера. |
| `max-compression` | 640 | 60 | 0.5 МБ | Минимальный размер. |
| `crosspoint` | 480 | 80 | 0.5 МБ | E-ink ридер Xteink X4: нативная ширина 480, оттенки серого. |

```bash
# пресет под e-ink ридер
ranobelib-epub "<ссылка>" --preset crosspoint

# ручная настройка (без --preset)
ranobelib-epub "<ссылка>" --max-image-width 900 --quality 70
```

### Профили `--charset`

Профиль задаёт, какие символы CrossPoint отрисует встроенным шрифтом. Кластеры
(эмодзи, составные знаки) удаляются целиком, чтобы не оставлять невидимых остатков;
число удалённых символов попадает в отчёт.

- `builtin` — встроенный диапазон шрифта CrossPoint (латиница, кириллица, основная
  пунктуация). Знака `№` (U+2116) в нём нет.
- `builtin+symbols` — добавляет буквенные символы, стрелки, математику, значки,
  псевдографику.
- `builtin+symbols+cjk` — добавляет хирагану, катакану, кандзи и полноширинные формы.
- `full` — весь Unicode, кроме управляющих символов. Преобразование символов не
  выполняется.

### Метка `18+`

Возрастное ограничение на сайте — клиентская декларация. Если у книги метка `18+`,
утилита подтверждает её автоматически и пишет об этом в отчёт; интерактивного диалога
нет. Это не обход авторизации: главы, требующие учётной записи, пропускаются с
причиной в отчёте.

### Коды возврата

- `0` — файл собран (частичные потери не считаются ошибкой: они перечислены в отчёте).
- `1` — сбой сборки (сеть, книга не найдена, прерывание).
- `2` — некорректный параметр.

## Возможности

- Интерактивный TUI (выбор перевода, подтверждение, прогресс, отчёт) и
  неинтерактивный режим для скриптов.
- Выбор команды-переводчика с покрытием глав; непокрытые главы добираются из
  актуальной ветки, их номера можно посмотреть заранее.
- Автоматическое подтверждение метки `18+` (клиентская декларация возраста, не обход
  авторизации).
- Скачивание и сжатие иллюстраций в JPEG, обложка книги; одинаковые по содержимому
  изображения встраиваются в архив один раз.
- Приведение набора символов к профилю CrossPoint с удалением эмодзи и иных
  неподдерживаемых кластеров целиком.
- EPUB 3 с корректной иерархией номеров глав (`1.25`, `15.12`, `1.22.5`) и отчётом:
  путь, размер, пропуски, число удалённых символов.

## Требования

- Python 3.14+ и [uv](https://docs.astral.sh/uv/).
- Для самопроверки файла — Java 17+ и `epubcheck` (необязательно).

## Готовые бинарные сборки

Готовые исполняемые файлы публикуются в [GitHub Releases](https://github.com/OranGeNaL/ranobe-to-epub/releases).
Такой файл не требует установки Python, uv и каких-либо пакетов — достаточно скачать
файл под вашу платформу и запустить.

| Платформа | Файл | Требования |
| --- | --- | --- |
| Linux x86_64 | `ranobelib-epub-linux-x86_64` | glibc 2.35+ (Ubuntu 22.04+, Debian 12+, RHEL 9+ и совместимые) |
| macOS arm64 | `ranobelib-epub-macos-arm64` | macOS 15+ (Apple Silicon, Mac с 2020 года и новее) |
| Windows x86_64 | `ranobelib-epub-windows-amd64.exe` | Windows 10/11 x64 |

Сборок под macOS Intel в настоящее время нет из-за отсутствия доступных
инструментов компиляции под эту архитектуру; на таких машинах используйте
установку через uv ниже.

Запуск совпадает с обычным:

```bash
# Linux/macOS
./ranobelib-epub-linux-x86_64 "<ссылка>"

# Windows
ranobelib-epub-windows-amd64.exe "<ссылка>"
```

### Проверка скачанного файла

Вместе с бинарными файлами в Release лежит `checksums.txt` с контрольными суммами
SHA-256. Проверить целостность скачанного файла можно так:

```bash
sha256sum -c checksums.txt   # Linux/macOS
certutil -hashfile ranobelib-epub-windows-amd64.exe SHA256  # Windows
```

На Windows одно из предупреждений — «Неизвестный издатель» от SmartScreen: бинарные
файлы не подписаны сертификатом. Это ожидаемо для этой сборки; перед запуском
файла сверьте его контрольную сумму, следуя инструкции выше.

## Отказ от гарантий

API `ranobelib.me` не документирован и может измениться в любой момент; совместимость
не гарантируется. Утилита предназначена только для личного чтения и не заменяет
поддержку авторов и переводчиков. Соблюдайте условия использования сайта.

## Установка из исходников (uv)

Для запуска из исходного кода нужны Python 3.14+ и
[uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

Запуск без установки в окружение:

```bash
uv run ranobelib-epub "<ссылка>"
```

Этот способ подходит, в частности, для macOS Intel и Linux arm64, для которых
готовых бинарных сборок нет.

## Разработка

```bash
uv run ruff check
uv run pytest
```

Проверка EPUB 3 (если установлен `epubcheck`; путь задаётся `EPUBCHECK_JAR` или
`EPUBCHECK`):

```bash
EPUBCHECK_JAR=/path/to/epubcheck.jar uv run pytest
```

Контрактный тест требует сеть и по умолчанию пропускается:

```bash
RANOBELIB_CONTRACT=1 uv run pytest -m contract
```

Локальная сборка самодостаточного бинаря (тем же способом, что и в CI):

```bash
uv run python -m nuitka \
  --mode=onefile --python-flag=-m \
  --assume-yes-for-downloads --update-check=never \
  --output-dir=dist \
  --output-filename=ranobelib-epub-macos-arm64 \
  src/ranobelib_epub
```

Сборка занимает несколько минут (компиляция C-кода). Артефакты появляются в
`dist/`; после проверки их можно удалить, в репозиторий они не входят.
