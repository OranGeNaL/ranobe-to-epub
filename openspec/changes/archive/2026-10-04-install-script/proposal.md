## Why

Сейчас установка требует либо Python 3.14 + uv, либо ручного скачивания бинарного файла из GitHub Releases и его последующего запуска. README начинается с инструкции через `uv sync`, что отсекает пользователей без окружения Python. Нет привычной для популярных проектов установки в одну строку (`curl ... | sh`), из-за чего вход в проект для нового пользователя выше, чем мог бы быть.

## What Changes

- В самом начале `README.md` размещается раздел «Установка» с командой установки в одну строку: `curl -fsSL <url> | sh` для macOS/Linux и `irm <url> | iex` для Windows.
- Появляется bash-скрипт установки для macOS и Linux: определяет платформу и архитектуру, получает из GitHub Releases самую свежую версию утилиты, скачивает подходящий бинарный файл и устанавливает его в подходящую директорию.
- Появляется PowerShell-скрипт установки для Windows: то же самое, но для Windows x86_64.
- Скрипты проверяют скачанный файл по контрольной сумме SHA-256 из `checksums.txt` релиза перед установкой.
- Утилита по-прежнему доступна через uv; новые скрипты дополняют этот путь, а не заменяют его.

## Capabilities

### New Capabilities
- `install`: установка утилиты в одну строку для macOS, Linux и Windows — скрипты, которые получают последний релиз из GitHub Releases, проверяют его целостность и размещают бинарный файл в подходящей для платформы директории.

### Modified Capabilities
- (пусто) — поведение самой утилиты не меняется; меняется только способ её доставки и документация.

## Impact

- **README.md**: перестраивается — раздел «Установка» переносится в начало, добавляются однострочные команды для всех трёх платформ.
- **Новые файлы**: `install.sh` (macOS/Linux) и `install.ps1` (Windows) в корне репозитория; их содержимое доступно по raw-ссылкам GitHub.
- **GitHub Releases**: скрипты зависят от существующих артефактов релизов (`ranobelib-epub-linux-x86_64`, `ranobelib-epub-macos-arm64`, `ranobelib-epub-windows-amd64.exe` и `checksums.txt`); изменения в пайплайне сборки не требуются.
- **Зависимости**: новых зависимостей нет; скрипты используют только штатные утилиты ОС (`curl`, `uname`, `sha256sum`/`shasum`, `Install-Script`-эквивалент PowerShell — `Invoke-RestMethod`, `Get-FileHash`).
- **Безопасность**: скрипты должны быть консервативны — не принимать аргументы, выполняющие произвольный код, и проверять целостность скачанного файла.
