## Purpose

Устанавливает утилиту ranobelib-epub в одну строку для macOS, Linux и Windows: скрипт получает последний релиз из GitHub Releases, проверяет целостность скачанного файла и размещает бинарный файл в подходящей для платформы директории.

## ADDED Requirements

### Requirement: Однострочная команда установки в README
Система SHALL размещать в самом начале README.md раздел «Установка», содержащий команду установки в одну строку: `curl -fsSL <URL> | sh` для macOS/Linux и `irm <URL> | iex` для Windows. URL SHALL указывать на скрипты установки в репозитории проекта на GitHub.

#### Scenario: Инструкция для macOS/Linux в начале README
- **WHEN** пользователь открывает README.md
- **THEN** первым содержательным разделом является «Установка» с командой `curl -fsSL <URL> | sh`

#### Scenario: Инструкция для Windows в начале README
- **WHEN** пользователь открывает README.md
- **THEN** раздел «Установка» также содержит команду `irm <URL> | iex` для Windows

### Requirement: Получение последней версии из GitHub Releases
Скрипт установки SHALL получать из GitHub Releases самую свежую опубликованную версию утилиты и скачивать бинарный файл, соответствующий платформе и архитектуре пользователя, не требуя указания номера версии вручную.

#### Scenario: Установка последней версии
- **WHEN** пользователь запускает скрипт установки без указания версии
- **THEN** скрипт определяет последний опубликованный релиз через GitHub API и скачивает бинарный файл из этого релиза

#### Scenario: Нет доступа к сети
- **WHEN** скрипт установки не может получить данные о последнем релизе
- **THEN** установка завершается ошибкой с понятным сообщением и ненулевым кодом возврата

### Requirement: Установка в подходящую директорию
Скрипт установки SHALL размещать бинарный файл в директорию, подходящую для платформы и допустимую для пользователя без прав администратора, и сообщать пользователю путь установки.

#### Scenario: Установка в домашнюю директорию пользователя
- **WHEN** пользователь запускает скрипт установки без прав администратора
- **THEN** бинарный файл устанавливается в директорию внутри домашней директории пользователя (например, `~/.local/bin` на macOS/Linux и `%LOCALAPPDATA%\Programs` на Windows) без запроса прав администратора

#### Scenario: Сообщение о пути установки
- **WHEN** установка завершается успешно
- **THEN** скрипт выводит путь, по которому установлен бинарный файл, и подсказку о добавлении директории в PATH, если она ещё не в PATH

### Requirement: Проверка целостности скачанного файла
Скрипт установки SHALL проверять контрольную сумму SHA-256 скачанного бинарного файла против `checksums.txt` из того же релиза до установки.

#### Scenario: Контрольная сумма не совпадает
- **WHEN** контрольная сумма скачанного файла не совпадает с указанной в `checksums.txt`
- **THEN** установка прерывается, файл не устанавливается, выводится сообщение об ошибке целостности

#### Scenario: Контрольная сумма совпадает
- **WHEN** контрольная сумма скачанного файла совпадает с указанной в `checksums.txt`
- **THEN** установка продолжается и завершается успешно

### Requirement: Поддержка платформ
Скрипт установки SHALL поддерживать macOS arm64, Linux x86_64 и Windows x86_64 — платформы, для которых публикуются бинарные файлы. Для платформы, для которой бинарный файл не публикуется (например, macOS Intel), скрипт SHALL сообщить об отсутствии сборки и предложить установку через uv.

#### Scenario: Поддерживаемая платформа
- **WHEN** пользователь запускает скрипт на платформе, для которой есть бинарный файл
- **THEN** скрипт выбирает файл с именем, соответствующим платформе и архитектуре, и устанавливает его

#### Scenario: Неподдерживаемая платформа (macOS Intel)
- **WHEN** пользователь запускает скрипт установки на macOS Intel
- **THEN** скрипт сообщает, что сборки под эту платформу нет, предлагает установку через uv и завершается с ненулевым кодом возврата

### Requirement: Безопасность исполнения
Скрипты установки SHALL быть консервативными: они выполняются в оболочке пользователя, поэтому не должны выполнять произвольный код из аргументов командной строки и должны завершаться с ошибкой при любой непредвиденной ситуации вместо продолжения с некорректными данными.

#### Scenario: Строгий режим оболочки
- **WHEN** любой шаг скрипта установки завершается ошибкой
- **THEN** скрипт немедленно прекращает работу и завершается с ненулевым кодом возврата
