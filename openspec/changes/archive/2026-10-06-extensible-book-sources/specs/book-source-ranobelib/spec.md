## ADDED Requirements

### Requirement: RanobeLib как модуль источника
RanobeLib SHALL реализовываться как отдельный модуль, соответствующий контракту `book-source-api`, и SHALL регистрироваться в реестре источников для ссылок на `ranobelib.me`. Модуль SHALL самостоятельно содержать все данные своего сайта: базовый адрес API, обязательные заголовки `Site-Id`/`Origin`/`Referer`, origin сайта и заголовки CDN для иллюстраций, а также политику возрастного ограничения `18+`. Разбор ссылки, получение данных книги и наблюдаемое поведение сборки MUST оставаться прежними.

#### Scenario: Ссылка RanobeLib выбирает модуль RanobeLib
- **WHEN** пользователь передаёт ссылку на книгу `ranobelib.me`
- **THEN** реестр выбирает модуль RanobeLib и дальнейшие данные приходят через него

#### Scenario: Site-specific данные локализованы в модуле
- **WHEN** модуль RanobeLib обращается к API или скачивает иллюстрацию
- **THEN** базовый адрес, заголовки и origin берутся из самого модуля, а не из общих констант приложения

#### Scenario: Поведение RanobeLib не меняется
- **WHEN** книга собирается после выделения модуля
- **THEN** результат сборки, метаданные, нумерация глав, выбор перевода и подтверждение возраста совпадают с прежним поведением
