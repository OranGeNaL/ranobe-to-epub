## ADDED Requirements

### Requirement: Редактируемые метаданные EPUB
Система SHALL позволять до записи файла переопределять основные метаданные EPUB: название (`dc:title`), автора (`dc:creator`), описание (`dc:description`), язык (`dc:language`), жанры (`dc:subject`), дату (`dc:date`), издателя (`dc:publisher`), а также название серии и номер тома. Пустое переопределение SHALL означать «использовать значение из данных сайта»; если и там значения нет, поле SHALL быть опущено.

Идентификатор книги (`dc:identifier`) MUST NOT переопределяться: он SHALL оставаться стабильным для одной книги между запусками. Переопределённые значения SHALL попадать во все документы, где используются метаданные: `package.opf`, `nav.xhtml`, `toc.ncx`, а также в имя файла по умолчанию.

Серия SHALL записываться средствами EPUB 3: `meta property="belongs-to-collection"` с `id`, `meta refines` с `collection-type` = `series` и `meta refines` с `group-position` для номера тома. Издатель SHALL записываться как `dc:publisher`.

Язык (`dc:language`) SHALL выбираться из фиксированного набора из 10 кодов: `ru`, `en`, `ja`, `zh`, `ko`, `de`, `fr`, `es`, `it`, `pt`. При переопределении языка значение SHALL быть одним из этого набора. Значение по умолчанию SHALL браться из данных сайта; если сайт не отдал язык, поле SHALL быть опущено.

Описание по умолчанию SHALL браться из метаданных книги, полученных с сайта (текст `summary`), и попадать в `dc:description` как обычный текст без разметки.

Дата по умолчанию SHALL быть датой сборки, как и прежде; при переопределении значение SHALL проверяться на формат `YYYY-MM-DD`. Остальные пустые поля SHALL брать значение из данных сайта, а при его отсутствии поле SHALL быть опущено.

#### Scenario: Переопределённые поля попадают в OPF
- **WHEN** пользователь задал название, автора, описание, язык, жанры, дату, издателя и серию с номером тома
- **THEN** `package.opf` содержит эти значения в `dc:title`, `dc:creator`, `dc:description`, `dc:language`, `dc:subject`, `dc:date`, `dc:publisher` и в `belongs-to-collection` с `group-position`

#### Scenario: Пустое поле берётся с сайта
- **WHEN** поле не редактировалось, а сайт отдал для него значение
- **THEN** в EPUB попадает значение с сайта

#### Scenario: Идентификатор не переопределяется
- **WHEN** метаданные книги не менялись между двумя сборками
- **THEN** `dc:identifier` совпадает в обоих файлах

#### Scenario: Имя файла по умолчанию следует за названием
- **WHEN** пользователь переопределил название и не задал путь вывода
- **THEN** имя файла по умолчанию формируется из переопределённого названия

#### Scenario: Язык выбирается из фиксированного набора
- **WHEN** пользователь переопределяет язык
- **THEN** доступны 10 кодов `ru`, `en`, `ja`, `zh`, `ko`, `de`, `fr`, `es`, `it`, `pt`, включая русский

#### Scenario: Описание берётся из данных сайта
- **WHEN** пользователь не менял описание, а сайт отдал `summary`
- **THEN** `dc:description` содержит текст описания без разметки

### Requirement: Выбор обложки из доступных вариантов
Система SHALL встраивать в EPUB ту обложку, которую выбрал пользователь из списка доступных обложек книги. По умолчанию SHALL использоваться обложка книги, полученная из `GET /manga/{slug_url}`. Система SHALL поддерживать отказ от обложки: в этом случае EPUB собирается без `cover-image`.

Выбранная обложка SHALL обрабатываться тем же образом, что и обложка по умолчанию: скачиваться, сжиматься по текущим настройкам сжатия и объявляться в манифесте как `cover-image` с соответствующей записью в метаданных. Если выбранную обложку скачать не удалось, система SHALL зафиксировать это в отчёте и собрать EPUB без обложки, не прерывая сборку.

#### Scenario: Выбрана обложка из карусели
- **WHEN** пользователь выбрал обложку тома из списка
- **THEN** в EPUB встраивается именно она и объявляется как `cover-image`

#### Scenario: Обложка по умолчанию
- **WHEN** пользователь не выбирал обложку
- **THEN** используется обложка книги из данных сайта

#### Scenario: Сборка без обложки
- **WHEN** пользователь отказался от обложки
- **THEN** EPUB не содержит `cover-image` и соответствующей записи в метаданных

#### Scenario: Выбранная обложка недоступна
- **WHEN** загрузка выбранной обложки завершается ошибкой
- **THEN** система записывает причину в отчёт и собирает EPUB без обложки

## MODIFIED Requirements

### Requirement: Сборка EPUB 3
Система SHALL собирать EPUB 3-контейнер со следующими обязательными частями: несжатый и первый по порядку файл `mimetype` со значением `application/epub+zip`, файл `META-INF/container.xml`, пакет `EPUB/package.opf`, документ навигации `EPUB/nav.xhtml`, а также NCX `EPUB/toc.ncx` для совместимости со старыми читалками. Система SHALL встраивать главы как XHTML-файлы, обложку как изображение с объявлением в OPF, а метаданные книги — как `dc:title`, `dc:language`, `dc:creator` (если известен), `dc:identifier`, `dc:description` (если известно), `dc:publisher` (если известен), `dc:subject` (жанры) и `dc:date`. Серия записывается как `belongs-to-collection` с `group-position` для номера тома. Идентификатор книги SHALL быть стабильным между запусками для одной и той же книги.

#### Scenario: Контейнер содержит обязательные части
- **WHEN** система собрала EPUB для одной главы
- **THEN** архив содержит `mimetype`, `META-INF/container.xml`, `EPUB/package.opf`, `EPUB/nav.xhtml` и `EPUB/toc.ncx`

#### Scenario: Файл mimetype несжат и идёт первым
- **WHEN** система открывает собранный архив
- **THEN** первой записью идёт `mimetype`, и она сохранена в режиме `STORE`

#### Scenario: Идентификатор стабилен между запусками
- **WHEN** EPUB собирается дважды для одной и той же книги
- **THEN** значение `dc:identifier` совпадает в обоих файлах

#### Scenario: Навигация перечисляет все главы в порядке чтения
- **WHEN** в книге 735 глав
- **THEN** `nav.xhtml` содержит 735 пунктов оглавления в том же порядке, что и файлы глав, и порядок совпадает с порядком сборки

#### Scenario: Язык книги указывается в OPF
- **WHEN** книга имеет `inLanguage = ru-RU`
- **THEN** OPF содержит соответствующий `dc:language`

#### Scenario: Некорректное имя файла главы
- **WHEN** имя главы содержит символы, запрещённые в имени файла
- **THEN** система заменяет их безопасными эквивалентами, сохраняя читаемость имени
