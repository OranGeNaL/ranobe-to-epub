## ADDED Requirements

### Requirement: Получение списка обложек книги
Система SHALL получать список доступных обложек книги через `GET /manga/{slug_url}/covers` тем же клиентом и с теми же обязательными заголовками, что и остальные запросы. Для каждой обложки модель SHALL содержать идентификатор, порядок в карусели (`order`), человекочитаемую метку (`info`) и URL выбранного размера. Список SHALL быть упорядочен по возрастанию `order`. Предпочтительный размер — `orig`, при его отсутствии `default`, затем `md`, затем `thumbnail`.

Отсутствие поля или недоступность эндпоинта MUST NOT прерывать сборку: система SHALL вернуть пустой список либо обложки без URL и продолжить с обложкой книги по умолчанию.

#### Scenario: Список обложек получен целиком
- **WHEN** система выполняет `GET /manga/{slug_url}/covers` для книги с каруселью обложек
- **THEN** модель содержит все обложки в порядке `order`, и у первой обложки метка совпадает с полем `info`

#### Scenario: Предпочитается полноразмерный вариант
- **WHEN** у обложки одновременно присутствуют `orig`, `default` и `thumbnail`
- **THEN** модель содержит URL из `orig`

#### Scenario: Размер orig отсутствует
- **WHEN** у обложки нет `orig`, но есть `default` и `thumbnail`
- **THEN** модель содержит URL из `default`

#### Scenario: Карусель пуста или недоступна
- **WHEN** эндпоинт возвращает пустой список или завершается ошибкой
- **THEN** система не прерывает сборку и использует обложку книги по умолчанию

## MODIFIED Requirements

### Requirement: Получение метаданных книги
Система SHALL получать метаданные книги и предоставлять их в виде типизированной модели: оригинальное название, русское название, обложка, статус (`Онгоинг`/`Завершена`), год выхода, жанры, автор, описание и ограничение по возрасту. Запрос карточки SHALL запрашивать расширенные поля `fields[]=authors`, `fields[]=genres` и `fields[]=summary`, потому что без них автор, жанры и описание приходят пустыми. Автор SHALL браться из `authors[].name` (при отсутствии — из `authors[].rus_name`), а несколько авторов SHALL объединяться в одну строку через `, `. Описание SHALL преобразовываться из ProseMirror-документа `summary` в обычный текст без разметки. Жанры SHALL браться из `genres[].name`. Если необязательное поле отсутствует, модель SHALL содержать `None` и сборка SHALL продолжаться.

#### Scenario: Метаданные книги читаются полностью
- **WHEN** система получает карточку книги с расширенными полями
- **THEN** модель содержит оригинальное и русское название, обложку, статус, год выхода, жанры, автора и описание

#### Scenario: Поля карточки запрашиваются с расширением
- **WHEN** система получает метаданные книги
- **THEN** запрос к карточке содержит `fields[]=authors`, `fields[]=genres` и `fields[]=summary`

#### Scenario: Автор читается из списка авторов
- **WHEN** карточка содержит `authors` с элементом `name = "Tappei Nagatsuki"`
- **THEN** поле автора в модели равно `Tappei Nagatsuki`

#### Scenario: Несколько авторов объединяются
- **WHEN** карточка содержит нескольких авторов
- **THEN** поле автора в модели содержит их имена, объединённые через `, `

#### Scenario: Описание преобразуется в текст
- **WHEN** карточка содержит `summary` в формате ProseMirror-документа
- **THEN** поле описания в модели содержит обычный текст без узлов разметки

#### Scenario: Жанры читаются из списка
- **WHEN** карточка содержит `genres` со списком объектов с полем `name`
- **THEN** модель содержит жанры с этими названиями

#### Scenario: Ограничение по возрасту присутствует
- **WHEN** карточка содержит поле ограничения по возрасту со значением `18+`
- **THEN** модель содержит ограничение по возрасту `18+`

#### Scenario: Необязательные метаданные отсутствуют
- **WHEN** карточка не содержит `authors`, `genres` или `summary`
- **THEN** соответствующие поля модели равны `None` (для жанров — пустой список) и сборка продолжается

#### Scenario: Книга без обложки
- **WHEN** карточка не содержит обложку
- **THEN** модель содержит `None` в поле обложки и сборка продолжается
