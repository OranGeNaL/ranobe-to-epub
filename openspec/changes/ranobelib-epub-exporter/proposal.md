## Why

Нужна консольная утилита, которая по ссылке на ранобэ на `ranobelib.me` выгружает все главы и собирает из них EPUB-файл. Сейчас такой сборки нет ни в одном инструменте: сайт отдаёт текст не в HTML, а в ProseMirror-JSON через закрытый-ish REST API, поэтому ни наивный скоринг, ни готовые «скачивалки» не работают. Хотим результат, пригодный для офлайн-чтения в любой читалке, с осмысленным выбором перевода и вменяемым размером файла.

## What Changes

- **Новая консольная утилита на Python 3.14 (пакетный менеджер `uv`)** с интерактивным TUI на `textual`; в неинтерактивном режиме (CI, скрипты) тот же код работает через флаги `--no-tui` и stdout.
- **Интеграция с API `ranobelib.me` (Mangalib).** Разбор пользовательской ссылки вида `/ru/book/{id}--{slug}` в `slug_url`; чтение метаданных книги, полного списка глав и текста глав.
- **Обход WAF.** API отдаёт `403` без заголовков `Site-Id`, `Origin` и `Referer`; клиент всегда их проставляет.
- **Рендеринг ProseMirror-JSON в XHTML** для глав: `paragraph`, `heading`, `text`, `image`, `hardBreak`, `horizontalRule`, `blockquote`, марки `bold`/`italic` и любые неизвестные узлы — без падения.
- **Иерархическая нумерация глав** по данным сайта, принцип родительский → дочерний: том 1 глава 25 → `1.25`, том 15 глава 12 → `15.12`. Дробные номера сайта (`22.5` — побочная история к главе 22) дают трёхуровневый номер `1.22.5`. Номер попадает в заголовок главы, оглавление и имя файла.
- **Автоматическое подтверждение возрастного ограничения** `18+` без взаимодействия с пользователем. На `ranobelib.me` это самодекларация возраста, а не защита: отметка хранится только в браузере, а содержимое отдаётся и без неё. Ограничения, требующие авторизации, обходятся не будут — такие главы попадают в отчёт.
- **Фильтрация символов под CrossPoint** — e-ink прошивку для Xteink. По умолчанию удаляются символы вне диапазонов встроенных шрифтов (эмодзи, астральная плоскость, Box Drawing), удаление идёт по целым графемным кластерам и учитывается в отчёте. Профили: `builtin` (по умолчанию), `+symbols`, `+cjk`, `full`.
- **Сжатие иллюстраций.** Замер: картинка 5014 КБ → 229 КБ (JPEG 1280px q80, 22× экономии). WebP проверен и отклонён — EPUB 3 поддерживает его хуже. По умолчанию лимит включён, отключается флагом.
- **Сборка EPUB 3** собственным кодом на `zipfile` (без внешних EPUB-библиотек): `mimetype`, `META-INF/container.xml`, `OPF` с метаданными книги, навигация `nav.xhtml`, NCX для старых читалок, встроенные сжатые JPEG внутри `EPUB/Images/`.
- **Интерактивный выбор перевода.** У части глав несколько веток перевода (на проверенной книге — до 3). TUI предлагает актуальную ветку по умолчанию, даёт выбрать другую, и явно показывает, что выбранный перевод доступен **только для части глав**.
- **Устойчивость.** Ограничение скорости запросов, повторы с экспоненциальной задержкой, частичный EPUB при недоступных главах, отчёт о пропущенных главах и нескачанных картинках.

## Capabilities

### New Capabilities
- `book-source-ranobelib`: разбор ссылки, HTTP-клиент к API `ranobelib.me` (заголовки, Site-Id, ретраи, троттлинг), получение метаданных книги, списка глав и текста глав, иерархическая нумерация глав, подтверждение 18+, выбор ветки перевода.
- `epub-build`: преобразование ProseMirror-JSON в XHTML, фильтрация символов под CrossPoint, загрузка и сжатие иллюстраций, сборка валидного EPUB 3, отчёт о пропусках.
- `tui-cli`: интерактивный TUI на `textual` — ввод ссылки, выбор перевода, прогресс-бар, отчёт; эквивалентный неинтерактивный режим по флагам.

## Impact

- **Новый код**: пакет `ranobelib_epub` (модули `cli`, `tui`, `source`, `prosemirror`, `charset`, `images`, `epub`, `models`).
- **Целевое устройство чтения**: CrossPoint Reader (прошивка e-ink ридеров, Xteink и совместимые). Фильтрация символов опирается на пресет `builtin` из `lib/EpdFont/scripts/fontconvert_sdcard.py`.
- **Новые зависимости** (runtime): `textual`, `httpx`, `pillow`. Инструменты: `uv`, `pytest`, `pytest-asyncio`.
- **Зависимости stdlib**: `zipfile`, `json`, `unicodedata`, `dataclasses` — EPUB собирается без сторонних библиотек.
- **Внешние системы**: только `ranobelib.me` (read-only GET). Авторизация не используется и не обходится.
- **Тестирование**: httpx MockTransport + зафиксированные JSON-фикстуры из реальных ответов API (в репозитории кода нет — тесты строятся вместе с ним).
